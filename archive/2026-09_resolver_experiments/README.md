# Resolver experiments, September 2026

Historical comparison runs from 2026-09-10 to 2026-09-18, moved here from
`reports/` on 2026-09-28. They explain why the opt-in token-to-PRO resolver
(`--marker-map`) is **not** the default. Nothing here is a current output, and
nothing here is regenerated by any command. The reproduce commands inside the
sub-READMEs show the original `reports/...` paths they were run with.

## What the experiments showed

1. **Stricter marker resolution lowered agreement with the provisional
   mappings.** With the same 80 provisional cases and 826-term axiom index,
   top-5 agreement fell from 19/80 (legacy) to 16/80 (explicit-policy
   resolver), and mean reciprocal rank fell from 0.152 to 0.108.
   See [resolver-refinement/](resolver-refinement/README.md).
2. **The drop came from evidence the stricter rules removed**, not from the
   alias additions or duplicate-clause fixes. Withholding generic CD3/CD8
   component assertions lost support for the expected targets and removed
   contradictions that had been keeping implausible competitors (e.g.
   CL:0002000) out of the top ranks. See [regression-triage/](regression-triage/README.md).
3. **One narrow correction was kept.** CL asserts the *whole* CD8 coreceptor
   (PR:000025402) on CL:0000625, which is a different case from inferring a
   complex from its alpha chain. The rule `whole_cd8_surface_positive_v1` in
   `src/soulcap_cl_mapping/marker_resolution.py` restores it in opt-in mode
   only. Top-5 agreement stayed at 16/80, so this is not a validated ranking
   improvement. See [regression-followup/](regression-followup/README.md).

All of these metrics measure agreement with **provisional** (unreviewed)
mappings. None of them measures biological accuracy.
