# literature/

Literature evidence that SOULCAP's markers define the cell types they claim to
(Milestone 2). Every quote is copied verbatim from its source and carries a
PMID, DOI or PMCID. Moved here from `reports/literature/` on 2026-09-28.

## What's here

| Path | What it is | Type |
|---|---|---|
| [evidence.tsv](evidence.tsv) | **The evidence table.** One row per (cell type, marker, quote). A quote that supports several markers appears once per marker. | Curated (edit by hand, then re-run `verify` and `views`) |
| [evidence_unplaced.tsv](evidence_unplaced.tsv) | Quotes from the narrative files that could not be placed mechanically (no marker, several markers not mentioned in the quote, no citation, no attribution line). Kept for a curator to place, never guessed. | Generated once by `migrate`; then curated |
| `by_cell_type/`, `by_marker/` | Read-only views of `evidence.tsv`. | Generated by `uv run soulcap-evidence views`; do not edit |
| [reviews/](reviews/README.md) | Review papers (index in `reviews.tsv`), starting with NK cells. | Curated |
| (archived) | The original narrative reports, one per cell-type family, are in [archive/2026-09_literature_narratives/](../archive/2026-09_literature_narratives/README.md). All their quotes were migrated into `evidence.tsv` on 2026-09-28. | Historical |

Not yet covered: monocyte, neutrophil, basophil, mast cell, granulocyte, MDSC
(see [ROADMAP.md](../ROADMAP.md) Milestone 2).

## evidence.tsv columns

`evidence_id` (stable, `EVnnnnn`), `subject_id` (a SOULCAP ID; blank until a
curator assigns one), `candidate_subject_ids` and `candidate_status`
(SOULCAP cell types in the family whose definition uses the marker; always
`unreviewed` until a curator confirms one as `subject_id`; `none_found` if no
family member uses the marker), `cell_type_label` (the family the source
covers),
`marker_token`, `level` (blank until curated), `supports_or_contradicts`
(`supports`, or `qualifies` for quotes under a discrepancy note), `quote`,
`pmid`, `doi`, `pmcid`, `first_author_year`, `species`, `tissue`,
`source_type` (`sorting_paper`, `review`, `atlas`, `other`),
`source_type_basis` (`pubmed_publication_type: …` when PubMed tags the paper
as a Review, otherwise `proposed; …` with PubMed's types for reference;
proposed types still need a curator's check), `source_file`, `source_line`, `section`, `notes`
(e.g. "Table 1"), `verified`, `verification_note`, `added_on`.

## Verification

`uv run soulcap-evidence verify` checks each quote against the open-access full
text in Europe PMC:

- `verified = yes`: every quoted fragment appears **exactly** in the full text
  (only whitespace is collapsed and Markdown bold/italic markers removed).
- `verified = exact_except_trailing_punctuation`: exact except the final
  `.`, `,`, `;` or `:` (usually a figure or reference marker in the paper at
  that point). Kept separate from paraphrases.
- `verified = no`: checked and not found exactly. `verification_note` says
  whether it was a near-match (differs only in case, dashes or quote marks) or
  how far it matched before diverging. **Quotes are never reworded to make them
  match**; a curator decides whether the quote or the citation is wrong.
- `verified = not_checked`: no open-access full text was available.

Quotes from `ilc_markers.md` and `t_cell_markers.md` were extracted with
WebFetch (an AI model copying page text), so they start as `no` and become
`yes` only through an exact full-text match; they are never `not_checked`.

## Rules

- Quotes are verbatim, never paraphrased, and always cited. If a paper could
  not be accessed, say so; never quote from memory or from an abstract you
  have not retrieved. Never write an identifier from memory.
- Paywalled papers are listed as inaccessible. Do not commit paywalled PDFs.
- "No evidence found" is a valid, recorded result.
- The `pro-marker-species-support`, `mapping-audit` and `soulcap-cl-matching`
  skills read `evidence.tsv`; older rows of
  [reports/pro_marker_species_support.tsv](../reports/pro_marker_species_support.tsv)
  cite the archived narratives by path.
- **Candidate cell types** come from a mechanical, unreviewed rule in
  `literature_evidence.py` (`FAMILY_ROOTS`): each Sheet row's Parent chain is
  followed to its root, and a dangling parent name counts as the root.
  γδ T cells are T-cell-family rows with `TCRgd+`; MAIT and iNKT are the rows
  with those abbreviations. The per-cell-type views label them "candidate".

## Commands

```bash
uv run soulcap-evidence migrate     # one-off: narrative files -> evidence.tsv (refuses to overwrite; --force)
uv run soulcap-evidence candidates  # candidate SOULCAP cell types per row (needs soulcap-sync data/)
uv run soulcap-evidence verify    # check quotes against Europe PMC full text (~7 min)
uv run soulcap-evidence views     # regenerate by_cell_type/ and by_marker/
```
